# 最终 checkpoint：50／60／70／80cm 固定高台评测

评测时间：2026-09-23。权重为最终 `model_9998.pt`，不是早期 `model_9000.pt`。
原始来源与哈希见 [results.json](results.json)，关节／观测／PD 的运行时解析见
[runtime_contract.json](runtime_contract.json)。

## 方法

64 个环境，每种高度 16 个；速度 0.6、1.0m/s，各用 seed 42、43。
每个高度共 64 次，合计 256 次；每次最多 10s，只计第一次尝试，自动 reset 不会增加试次。
原生 PyTorch 确定性 actor，无探索噪声，不更新网络。

平台长 1.5m、宽 2m，名义接近距离 1.5m。固定 heading=0，heading 增益 2、yaw_rate 限幅 ±π；
reset 扰动 x±0.1m、y±0.2m、yaw±0.08rad，关节按默认姿态静止重置。
关闭观测噪声、domain randomization 和课程；保留真实碰撞、自碰撞、原有动作缩放及 PD。
两个速度组使用配对的 reset seed。

上台必须连续 0.1s 满足：四轮中心都在台面内（边缘留 2cm），轮心高度距 `台高+0.086m`
不超过 6.5cm，至少两轮垂向支持力超过 5N，机身 gravity_z < -0.7。
通过必须已经上台，然后四轮越过后台沿至少 5cm、机身越过至少 35cm，四轮回到地面轮心高度
±8cm 范围，并保持支持及正姿态 0.2s。
首次终止、超时或机身侧向偏离超过 0.75m 即失败，不能绕行后记成功。

## 结果

| 固定高度 | 0.6m/s | 1.0m/s | 总通过率 |
|---|---:|---:|---:|
| 50cm | 32/32 | 32/32 | 64/64 = 100% |
| 60cm | 32/32 | 27/32 | 59/64 = 92.2% |
| 70cm | 32/32 | 27/32 | 59/64 = 92.2% |
| 80cm | 32/32 | 31/32 | 63/64 = 98.4% |
| 合计 | 128/128 | 117/128 | 245/256 = 95.7% |

未通过的 11 次中，9 次提前终止、1 次超时、1 次离开直线通道；没有“已经稳定上台但下台失败”的样本。
所有成功试次都满足完整上台与稳定落地判据。该结果只涵盖上述受控分布，不能等同实机或完整随机化成功率。
